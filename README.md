# 🐍 Nokia Classic Snake Game

A faithful recreation of the classic Nokia Snake game built with HTML5 Canvas and JavaScript.

## 🎮 Features

- **Authentic Nokia Snake Gameplay** - Grid-based movement just like the original
- **Auto-Restart** - Game automatically restarts 3 seconds after collision
- **Progressive Difficulty** - Game speed increases as you score more points
- **High Score Tracking** - Your high score is saved in browser storage
- **Smooth Controls** - Arrow keys or WASD to control the snake
- **Responsive Design** - Works on desktop and modern browsers

## 🕹️ How to Play

1. Click **START** to begin the game
2. Use **Arrow Keys** or **WASD** to control the snake direction
3. Eat the **red squares** (food) to grow longer and earn points
4. Each food eaten = **10 points**
5. Avoid hitting the **walls** or your own **body**
6. When you collide, the game automatically restarts after 3 seconds
7. Try to beat your **high score**!

## ⌨️ Controls

| Key | Action |
|-----|--------|
| **↑** or **W** | Move Up |
| **↓** or **S** | Move Down |
| **←** or **A** | Move Left |
| **→** or **D** | Move Right |

## 🎯 Game Mechanics

- Snake moves continuously in the current direction
- Food appears at random locations
- Snake grows by 1 segment when eating food
- Game speed increases with score
- Game ends on collision with walls or self
- Automatic restart after game over

## 💾 High Score

Your high score is automatically saved to your browser's local storage. It persists even after closing and reopening the game!

## 🛠️ Technical Details

- **Built with:** HTML5 Canvas, Vanilla JavaScript
- **No dependencies** - Pure JavaScript, works offline
- **Browser support:** All modern browsers (Chrome, Firefox, Safari, Edge)
